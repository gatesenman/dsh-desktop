# Security Policy / 安全政策

## Reporting a Vulnerability / 报告漏洞

Please **do not** open public issues or pull requests for security vulnerabilities.

请**不要**通过公开的 Issue 或 Pull Request 报告安全漏洞。

Report privately via GitHub Security Advisories:

请通过 GitHub Security Advisories 私下报告：

https://github.com/gatesenman/dsh-desktop/security/advisories/new

Include a description of the issue, steps to reproduce, and the potential impact if you can. We will review the report and respond as soon as possible.

请尽可能说明问题、复现步骤和潜在影响。我们会尽快审阅并回复。

## Scope / 范围

Please report issues such as leaked credentials, remote code execution, injection, authentication or authorization bypass, and similar vulnerabilities in this repository.

请报告本仓库中的凭证泄露、远程代码执行、注入、认证或授权绕过等安全问题。
