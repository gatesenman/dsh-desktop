# Contributing / 贡献指南

Thank you for your interest in this project. / 感谢你愿意参与本项目。

## Issues

- Search existing issues before opening a new one.
- Use the bug or feature templates when they are available.
- Include steps to reproduce, expected vs actual behavior, and environment details for bugs.

- 开新 Issue 前请先搜索是否已有同类问题。
- 若仓库提供了缺陷或功能模板，请使用模板。
- 报告缺陷时请写清复现步骤、期望与实际结果，以及运行环境。

## Pull Requests

- Keep changes focused and describe what you changed and why.
- Run the project’s existing tests or typecheck/build commands when they are documented in the README.
- Do not commit secrets, `.env` files with real values, `node_modules`, build output (`dist/`, `target/`, etc.), or logs.

- 请保持改动范围集中，并说明改了什么、为什么改。
- 若 README 中已有测试、类型检查或构建命令，请在提交前运行。
- 不要提交密钥、含真实配置的 `.env`、`node_modules`、构建产物（如 `dist/`、`target/`）或日志。

## Local development / 本地开发

See the README for how to build and run from source.

从源码构建与运行的步骤见仓库 README。

## Security / 安全

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).

请勿在公开 Issue 中报告安全漏洞，请遵循 [SECURITY.md](SECURITY.md)。
